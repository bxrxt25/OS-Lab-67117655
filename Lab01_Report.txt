1. Hardware Baseline:

- Number of CPU Cores: 2 Cores
- Total RAM: 7.76 GB

2. Observation (from htop during stress test):
จากการสังเกตผ่านหน้าต่าง htop พบว่าการใช้งาน CPU มีการสลับเปอร์เซ็นต์ขึ้นลงระหว่างทั้ง 2 คอร์ ไม่ได้ค้างอยู่ที่ 100% เพียงคอร์เดียวแบบตายตัว สิ่งนี้เกิดขึ้นเพราะระบบปฏิบัติการ (OS Scheduler) ทำการสลับการทำงานของโปรแกรม (Context Switching) ไปมาระหว่างคอร์ อย่างไรก็ตาม โปรแกรม Python นี้ทำงานแบบ Single-thread จึงดึงทรัพยากร CPU ไปใช้รวมแล้วสูงสุดเทียบเท่ากับพลังของ CPU เพียง 1 คอร์ (100%) เท่านั้น ไม่สามารถทำงานแบบคู่ขนานเพื่อใช้เต็ม 2 คอร์พร้อมกัน (200%) ได้

3. Analysis:
ในงาน Machine Learning ที่มีข้อมูลขนาดใหญ่ (เช่น รูปภาพ 500,000 รูป) การทราบข้อจำกัดของ OS และฮาร์ดแวร์มีความสำคัญมากดังนี้:
- Memory (RAM) Limits: หากเราพยายามโหลดรูปภาพทั้ง 500,000 รูปเข้าไปในหน่วยความจำพร้อมกัน ขนาดของข้อมูลอาจจะใหญ่เกินขีดจำกัดของ RAM (ที่เรามีอยู่เพียง 7.76 GB) ซึ่งจะทำให้ระบบเกิดข้อผิดพลาด Out of Memory (OOM) และโปรแกรมหยุดทำงาน การทราบลิมิตนี้จะช่วยให้เราออกแบบการทยอยโหลดข้อมูลทีละกลุ่มย่อย (Batch) ได้อย่างเหมาะสม
- CPU Core Counts: การทราบว่าระบบมี CPU หลายคอร์ (เช่น 2 คอร์) จะทำให้เรารู้ว่าเราไม่ควรเขียนโค้ดแบบ Single-thread (ที่ใช้พลังประมวลผลได้แค่เทียบเท่า 1 คอร์) แต่ควรใช้ไลบรารีที่รองรับการทำงานแบบคู่ขนาน (Multiprocessing) เพื่อแบ่งงานให้ CPU ทุกคอร์ช่วยกันประมวลผล ซึ่งจะช่วยลดระยะเวลาในการเตรียมข้อมูลและเทรนโมเดลลงได้อย่างมาก
